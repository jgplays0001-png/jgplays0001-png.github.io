# Privacy Policy - Pi Shorts Uploader

Last updated: November 15, 2026

Pi Shorts Uploader is a personal tool used only by its owner to upload videos to the owner's own YouTube channel.

**What it accesses:** With the owner's permission, it uses the YouTube Data API to upload videos and set their title, description and tags. It does not read, collect or share any other Google or YouTube data.

**Storage:** The sign-in token is stored only on the owner's own Raspberry Pi. No data is sent to anyone else, sold, or used for ads.

**Removing access:** Access can be removed at any time at https://myaccount.google.com/permissions

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
